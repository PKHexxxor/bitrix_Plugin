# Bitrix24 Conditional Fields

Eine einfache App für bedingte Felder und zweispaltiges Layout in Bitrix24 Smart-Prozessen.

## Installation

1. Lade diese Dateien auf GitHub hoch.
2. Rufe die URLs der Dateien auf GitHub ab.
3. In Bitrix24, gehe zu "Lokale Anwendung" und konfiguriere:
   - Handler-Pfad: URL zur `handler.php` auf GitHub
   - Zugriffsrechte: CRM

## Verwendung

Nach der Installation wird die App automatisch aktiv, wenn ein Smart-Prozess geöffnet wird.
Das Layout wird automatisch in zwei Spalten aufgeteilt und bedingte Felder werden entsprechend angezeigt/versteckt.

## Konfiguration

Die Konfiguration erfolgt über die Admin-Oberfläche, die über das App-Menü in Bitrix24 aufgerufen werden kann.
